# Operations: sessions-frontdesk

Purpose: everything a person needs to run, publish or debug this tool without reading the code. Values here are facts about the running tool; work items live in `PROJECT-STATUS.md`.

## What it does

A one-page Front Desk Playbook for Sessions Retreat's desk staff: what to offer, how to charge each one in Cloudbeds with screenshots, food and drink, the price list and a short self-check. The owner gets one place where every desk price matches Cloudbeds. The Burgundy has a twin page (burgundy-frontdesk). The Echo Command Center's Front desk tab links to it.

## Address

`https://echo-designs.github.io/sessions-frontdesk/` since the transfer to Echo-Designs (2026-10-21 to 22). The old address under Matt's account no longer answers (404); GitHub does not redirect Pages addresses after a transfer.

## Inputs and outputs

| Direction | System | What | How often |

## Schedule

None. GitHub Pages republishes the site on each push to `main`. The page content changes only when the build script is run and its output published (last on 2026-10-01).

## How it is built and published

- Built by the front-desk-playbooks build script (`build.py`), kept with Echo's code in Matt's Dropbox (the front-desk-playbooks scripts row in the echo-os register), not in this repository. It reads Cloudbeds, renders this page and the Burgundy twin, and refuses to finish if a price disagrees with Cloudbeds or the owner's decisions.
- Published by that folder's `publish.py`, which commits `index.html` and the images to this repository through the GitHub API in one commit.
- GitHub Pages serves `main` from the repository root (legacy build, no custom domain). The repository is public.
- Published files: `index.html`, `assets/` (logo and the three Cloudbeds screenshots), `robots.txt`. `_config.yml` excludes README.md, CLAUDE.md, AGENTS.md, docs/, templates/ and the dot files.
- The repository has no workflow.

## Hotel-specific values

The whole page is Sessions Retreat's: hotel name, logo, brand fonts and colours, prices and rules. All of it is generated by the build script; nothing here is hand-maintained.

## Deploy

A push to `main` republishes the site. At cut-over nothing moves: the site already publishes from this Echo-Designs repository. Add a `DEPLOY-LOG.md` entry with the commit and the Pages build result.
